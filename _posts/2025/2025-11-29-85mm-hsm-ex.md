> 85mm: Từ Người Bạn Đường Tin Cậy Đến Nàng Thơ Đỏng Đảnh

Người viết: Tuấn Anh (Anh Hàng Xóm Visual )

Thiết bị: Canon R8 & Sigma 85mm f/1.4 EX DG HSM

Hồi ức: Canon 85mm f/1.8 USM (Giai đoạn 5D2 - RP)

# 1. Hồi ức về Canon 85mm f/1.8 USM: Sự nuối tiếc của 3 năm thanh xuân

 Trước khi đến với khẩu độ f/1.4 đầy mê hoặc, tôi đã có 3 năm "**chinh chiến**" cùng Canon 85mm f/1.8 USM. Từ những ngày đầu chập chững với Canon 5D Mark II, qua Canon RP và chớm nở cùng Canon R8, ống kính này như một người bạn tri kỷ: Nhẹ, Nhanh và Lành.

*   **Sự tin cậy:** Nó chưa bao giờ phản bội tôi. Dù trên OVF của 5D2 hay EVF của R8, nó lấy nét nhanh như một cái chớp mắt.
*   **Sự linh hoạt**: Nhỏ gọn, nhét vừa mọi túi áo, không cần filter cầu kỳ, cứ đưa lên là chụp.

**Nỗi nhớ:** Giờ đây, khi cầm con Sigma EX nặng trịch, đôi lúc tôi thèm cái cảm giác nhẹ tênh ngày cũ, thèm sự đơn giản "chụp là nét" mà không cần lo nghĩ về viền tím hay soft focus.

> Chia tay sự an toàn, tôi đến với **Sigma 85mm EX** - một ống kính "vỏ nhung" cũ kỹ, mang vẻ đẹp Wabi-sabi nhưng cũng đầy tật xấu.

Tôi đến với 85mm này cũng giống như đến với canon r8, chỉ biết là khi đến được tầm này, chất lượng ảnh sẽ rất khác, 1 món hời, đắn đo với 135mm f2 l của canon đắt hơn 2 triệu, thật đáng tiếc hôm đó ra chỗ người bán không có 135mm. Rồi lỗi lo vì tôi đã từng dùng 85mm rất khó khăn trong không gian hẹp, nay 135mm thì tính sao.

# 2. Sigma 85mm f/1.4 EX DG HSM: "Cầm cương ngựa chứng" trên Canon R8

#### **Trải nghiệm thực tế:** "Đau đầu" nhưng "Đã mắt"

*   Thử thách **ND Filter:** Để tận dụng khẩu f/1.4 giữa trời nắng trên Canon R8 (max shutter cơ khí thấp), tôi buộc phải dùng ND Filter. Thiếu nó, **bokeh bị cắt cụt** và ảnh cháy sáng. Nó không cho phép sự lười biếng như hồi dùng 85mm USM.
*   Lấy nét "mong manh": Dù Canon R8 có Dual Pixel AF thần thánh, nhưng khi điều khiển **motor HSM đời cũ**, cảm giác lấy nét vẫn có **độ trễ nhẹ** (breathing). Nó không "bụp" ăn ngay, mà từ tốn, buộc tôi phải **chậm** lại.

#### **Vẻ đẹp của sự không hoàn hảo** (The Imperfect Beauty)

*   Khác với sự sắc nét đến gai người của dòng Art hay RF đời mới, Sigma EX mang lại:
*   Chất ảnh **Dreamy**: Tại f/1.4, hiện tượng cầu sai (spherical aberration) tạo ra một lớp "Glow" tự nhiên làm mềm da mẫu.
*   **Màu sắc hoài cổ**: Lớp tráng phủ cũ cho ra tông màu ấm, hơi vàng, rất hợp với concept "**Cinematic Muse**" mà tôi theo đuổi.
*   Hiệu ứng quang học: **Viền tím** và hiện tượng **"mù sương"** (veiling glare) khi ngược nắng, nếu kiểm soát tốt bằng L**ens Hood,** lại trở thành một thủ pháp nghệ thuật chứ không còn là lỗi.

        function calculateRecommendation() {
            const lowlight = document.getElementById('check-lowlight').checked;
            const bokeh = document.getElementById('check-bokeh').checked;
            const budget = document.getElementById('check-budget').checked;
            const sport = document.getElementById('check-sport').checked;
            const travel = document.getElementById('check-travel').checked;

            let canonScore = 0;
            let sigmaScore = 0;

            // Logic weights
            if (lowlight) { sigmaScore += 3; canonScore += 1; } // f1.4 wins
            if (bokeh) { sigmaScore += 3; canonScore += 1; }    // Sigma creamier
            if (budget) { canonScore += 4; }                    // Canon cheap
            if (sport) { canonScore += 3; sigmaScore += 0; }    // Canon USM faster
            if (travel) { canonScore += 2; sigmaScore -= 1; }   // Canon lighter

            const resultLens = document.getElementById('result-lens');
            const resultDesc = document.getElementById('result-desc');
            const resultDiv = document.getElementById('result-score');

            resultDiv.style.opacity = 1;

            if (!lowlight && !bokeh && !budget && !sport && !travel) {
                resultLens.innerText = "Hãy chọn tiêu chí...";
                resultLens.className = "text-3xl font-bold text-white mb-2";
                resultDesc.innerText = "Chọn các ô bên trái để xem ống kính nào phù hợp với phong cách chụp của bạn.";
                resultDiv.style.opacity = 0;
                return;
            }

            if (sigmaScore > canonScore) {
                resultLens.innerText = "Sigma 85mm f/1.4";
                resultLens.className = "text-3xl font-bold text-orange-500 mb-2";
                resultDesc.innerText = "Bạn cần chất lượng hình ảnh đỉnh cao, bokeh mượt mà và khả năng chụp thiếu sáng tốt nhất, chấp nhận nặng hơn và đắt hơn.";
            } else if (canonScore > sigmaScore) {
                resultLens.innerText = "Canon 85mm f/1.8";
                resultLens.className = "text-3xl font-bold text-red-500 mb-2";
                resultDesc.innerText = "Sự lựa chọn thông minh! Bạn sẽ có một ống kính lấy nét siêu nhanh, nhẹ nhàng và tiết kiệm chi phí mà vẫn cho ảnh chân dung rất đẹp.";

                resultLens.innerText = "Cân nhắc kỹ...";
                resultLens.className = "text-3xl font-bold text-stone-300 mb-2";

            }
        }
